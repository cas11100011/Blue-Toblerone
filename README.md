# Blue-Toblerone
This repository is of the Blue Toblerone group for their ECE 111 final project.

A terminal app for USeP students: Pomodoro timer & study logs, calendar and
project/event itinerary, budget tracker, and sleep & burnout tracker.

The study pie chart always prints as text. For a pop-up chart, install matplotlib.

py -3.15 main.py (Windows)
python3.15 main.py (Mac/Linux)
